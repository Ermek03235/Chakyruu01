# Приглашение Нурдөөлөт и Динары — 23.11.2026

Готовый статический сайт для GitHub Pages. Сборка и сервер не нужны.
Включены юрта с открывающейся дверью, переход внутрь, музыка, календарь и данные свадьбы.

## Загрузка через браузер

1. Распакуйте ZIP на компьютере.
2. Откройте нужный репозиторий GitHub (или создайте новый публичный, например wedding).
3. Нажмите Add file → Upload files.
4. Перетащите СОДЕРЖИМОЕ распакованного архива: index.html, design.css, yurt.css, design.js, README.md и папку assets целиком.
   Не загружайте сам ZIP и не помещайте файлы в дополнительную общую папку.
   Файл index.html должен лежать прямо в корне репозитория. Сохраните имена файлов и структуру assets.
5. Нажмите Commit changes.
6. Откройте Settings → Pages.
7. В Source выберите Deploy from a branch.
8. В Branch выберите main (либо ветку, куда загрузили файлы), папку / (root), затем Save.
9. Дождитесь публикации. GitHub покажет адрес и кнопку Visit site. Первая публикация может занять до 10 минут.

Если репозиторий называется wedding, адрес обычно имеет вид:
https://ВАШ-ЛОГИН.github.io/wedding/
Точный рабочий адрес скопируйте из Settings → Pages после публикации.

Если обновляете старый репозиторий с другим сайтом, его index.html будет заменён этим приглашением.
Чтобы сохранить старый сайт, создайте отдельный репозиторий.

## Проверка

Откройте опубликованный сайт на телефоне. Нажмите на дверь юрты: начнётся переход внутрь и музыка.
Кнопка ♪ включает и выключает музыку, ⌂ возвращает к виду юрты снаружи, ↗ копирует текущую ссылку.
Все пути относительные: сайт работает как в корне домена, так и в подпапке GitHub Pages.
Google Fonts загружаются из интернета; при недоступности используются системные шрифты.
